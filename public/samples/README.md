# Sample clips

Drop the sample videos referenced by `components/sports.ts` here. Filenames
must match the `samples[].src` paths exactly:

- `soccer-offside.mp4`
- `soccer-penalty.mp4`
- `football-pi.mp4`
- `football-fumble.mp4`
- `lacrosse-slash.mp4`
- `lacrosse-crease.mp4`

Until they exist, the sample buttons show an inline "not available yet" note —
the rest of the UI works without them.
